二、相关知识

#include <stdio.h>
 
int main()
{
    printf("Hello, World!");
    return 0;
}

#include <stdio.h>：预处理器指令，引入标准输入输出库，使 printf 函数可用。

int main()：主函数，C 程序的唯一入口，程序从这里开始执行。

printf(“Hello, World!”);：将字符串 Hello, World! 原样输出到屏幕，末尾未加 \n，因此输出后不换行，正好符合题目要求的“输出一行”且内容完全匹配。

01 Hugo+ananke的基础美化

Hugo的Ananke主题优化技巧

一、关于Hugo的各个目录功能

  • content：博客.md的文章存放位置。
  • layout：用于存放覆盖主题默认样式，修改外观的文件。
  • assets：存放自定义CSS和JS的位置。
  • static：图片等资源的存放地。
  • hugo.toml：全局设置配置文件。
  • themes/ananke：原始外观文件。

二、通过使用配置文件美化

在全局设置文件hugo.toml

[params]
  background_color_class = "bg-washed-blue"
#更换网页背景颜色
  featured_image_class = "cover bg-center"
#cover:覆盖，bg-center：覆盖

想要相关配置生效，还需要在文章开头加上

featured_image = "<相对路径>/在线URL"
#由于github的静态网页可能加载很慢，这里选择在线URL

三、开启文章目录

在每篇文章的 Front Matter 里加一行


toc = true

四、创建关于界面

先新建一个md文章，写入关于界面内容 然后在hugo.toml内加上

[[menu.main]]
  name = "关于"
  pageRef = "文件名（无需.md）"
  weight = 30

五、创建归档页面

在 content/ 下新建 archives.md

+++
title = "归档"
layout = "archives"
+++

在layouts/_default创建archives.html

开始-搭建博客

git使用以及搭建Hugo的Ananke主题博客

一、环境搭建

1.习惯养成

  • 每次通过apt install <包名>下载时，先用apt update更新软件包列表（其实有些时候好像并不好使）

2.安装go、hugo

  • 安装go
apt update
apt install golang-go
  • 安装hugo
#官方推荐debian系统使用apt安装
apt install hugo

不知道是apt问题还是什么原因，下载出来的版本是0.111.0（肯定更新完了啊）。。。。 官方最新版本发布页：https://github.com/gohugoio/hugo/releases 从这个页面获取最新版本的安装包，这里我找到的是0.165.0，https://github.com/gohugoio/hugo/releases/download/v0.165.0/hugo_withdeploy_0.165.0_linux-amd64.deb

wget https://github.com/gohugoio/hugo/releases/download/v0.165.0/hugo_withdeploy_0.165.0_linux-amd64.deb
dpkg -i  <文件目录>/安装包.deb

其他步骤和官网相同。

二 、git基础命令

git add .  #自动扫描项目中所有非排除文件的更改并上传
git add <文件路径>  #精准上传指定的文件夹或者文件
git commit -m "文件修改描述"  #提交时备注的修改描述
git push -f origin <分支名>  #选择要上传的分支
git init  #新建本地仓库
git branch  #查看当前有的分支
git checkout <分支名>  #切换分支
git push origin --delete <分支名>  #删除所选分支，删之前记得切换分支。
